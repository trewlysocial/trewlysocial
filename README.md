# 🦅 Trewly Social

**Trewly Social** is a modern social platform focused on speed, privacy, and intelligent interaction.  
Built with a powerful cross-platform architecture, Trewly delivers a native experience on mobile and web while integrating advanced features like Passkeys, real-time interactions, and AI-powered assistance. **Trewly Social**, an app of Lynix.

Experience Trewly live:

https://trewly.me

## ✨ Features

- 🔐 Passkeys authentication (biometric login)
- 💬 Threads, replies, and real-time interactions
- 🤖 AI assistant integration
- 📱 Native mobile app (Android Flutter)
- 🌐 Modern web platform
- ⚡ High-performance backend
- 🧠 Intelligent content and user interaction system
- 🛡️ Privacy-focused architecture

---

## 💻 Built with

Technologies used in the project:

### Frontend (Web)
- React
- Next.js (App Router)
- TypeScript

### Mobile App
- Flutter (Dart)
- Riverpod (state management)
- Go Router (navigation)
- Pusher Channels (real-time)
- Passkeys (WebAuthn support)

### Backend
- Node.js
- Next.js API Routes
- TypeScript
- Prisma ORM
- PM2 (process manager)

### Database
- PostgreSQL

### Authentication & Security
- WebAuthn / Passkeys
- TOTP (otplib)
- bcrypt (password hashing)
- JWT sessions

### Real-time & Notifications
- Pusher Channels

### AI & Content Moderation
- Perplexity API
- Self-hosted Hugging Face models (running on VPS)
- Sightengine (image and video moderation)

### Infrastructure
- Debian 12 VPS
- Nginx (reverse proxy)
- PM2
- Node.js runtime

### Media & System Integrations
- Image picker & cropper
- Audio recording & playback
- Video player & thumbnails
- Custom tabs & deep links
- Secure local storage

### Developer Tooling
- TypeScript
- Prisma
- npx
- Git
